# Write Adr

All repository paths below are relative to the repository root.

Read nearby entries in `docs/decisions/` and the source brief. Use the repository’s next unused numbered filename; do not renumber historical decisions.

Write the concrete context, options actually considered, decision and consequences. Explain the trigger and tradeoff in plain language. Cite the code or source that changes the decision; do not add unverified research claims or fictional consensus.

Distinguish an accepted choice from a proposal awaiting an owner decision. Record reversibility, migration impact or known limits when they affect implementation. Link the record from the relevant maintained contract rather than copying the same rationale into many files. Keep task chatter and discarded implementation details in `.coordination/` unless they explain a durable tradeoff.
