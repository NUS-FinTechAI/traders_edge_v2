# Contributing

Read [AGENTS.md](AGENTS.md) and [docs/plan.md](docs/plan.md) before editing.
Use a task branch and a small PR. Describe the change, reason, checks run and any reviewer focus. Run lint, type-check, build and relevant tests before committing.

Review correctness and scope on every PR. Review learning safety for simulation, rewards and copy; review visual changes against the approved direction. Merge only after reviews and CI pass. Update documentation in the same change when behavior changes.
