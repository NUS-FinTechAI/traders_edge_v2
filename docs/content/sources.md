# Source register

Primary investor-education sources were read on 2026-10-04. A reading date records source inspection, not independent approval of the authored lesson. Research papers below support specific mathematical definitions only. Examples, question wording, arithmetic inputs, progression rules and review intervals are authored for this project.

This register was compiled for the earlier ten-module catalog, which the game campaign replaced (see [ADR 0004](../decisions/0004-playable-game-overhaul.md)). The current campaign, scenario and quiz files do not cite these source IDs. The sources remain useful starting points for the independent content review the campaign still needs; their presence does not mean the campaign text was checked against them.

The core omits local taxes, named account benefits, deposit-protection limits, settlement-day counts and margin thresholds. Source pages can change; review the exact content edition before publication.
