# QA evidence

The walkthroughs and screenshots that used to live here recorded the retired
learning-run interface. They were removed when the playable game replaced it
([ADR 0004](../decisions/0004-playable-game-overhaul.md)); git history keeps
them.

QA evidence for the current client is captured per pull request: 390px
before/after screenshots of the changed screens, the states checked (loading,
empty, error, locked, success), keyboard and focus checks, and any checks that
could not be run. Follow the
[screenshot workflow](../../.devin/skills/capture-screenshots/SKILL.md) and
attach the evidence to the PR, or add a dated folder here only when a reviewer
asks for a retained record.
