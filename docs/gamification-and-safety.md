# Learning rewards and safety

Rewards recognize a verifiable learning event. The current API awards 20 XP for the first passed lesson, 50 for the first passed module check and 10 for the first passed delayed review. Repeating a passed item or retrying the same request does not earn the reward again. Activity days record rewarded learning in UTC, not trading. The optional leaderboard compares learning XP only and requires opt-in.

XP describes recorded completion, not skill, suitability or financial success. Profit, trade count, traded volume, order placement and increased leverage must never create rewards or ranks. A reasoned choice not to trade is valid. No reward may depend on sending funds or linking a brokerage account.

Standard stars can represent required learning completion in the interface. The authored optional reflection mission is a content prompt only; bonus-star awarding is not implemented. Submission reflection is stored but not assessed for quality, so it must not earn a badge claiming reflective competence. Cosmetic badges, titles, multiplayer ranks and endless practice are not implemented by this curriculum package. Eligibility metadata must not be mistaken for an available mode.

The curriculum teaches essential-money protection before markets, products and portfolio construction, then execution and risk. Each later hypothetical trade decision requires a plan written before the future path is known. Advanced lessons teach obligations and reasons to abstain; leverage and shorting never become defaults. The lesson catalog contains no executable trades, current trade recommendations, live alerts or future scenario paths.

Keep the core jurisdiction-neutral. Product-specific contract terms, tax, account rules, settlement periods, margin thresholds and reporting channels require reviewed localization. Current sources include US and Spanish regulators, but their local legal rules are not copied into the core. Content remains pending independent financial-accuracy review; production publication must fail closed until that review is recorded.

The interface must not use loss-chasing prompts, broken-streak shame, countdowns, urgent market notifications, order confetti, profit leaderboards, one-swipe execution or copy-trading. The fox may help explain a misconception; it must not pressure the learner, praise financial gains or express disappointment at a break.
