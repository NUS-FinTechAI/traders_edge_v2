# Evaluation plan

This is a proposed study, not a report of measured learning improvement. No participant outcome, effect size or profitability claim is established by the current application.

The first question is whether beginners understand trading concepts and risks and can apply them in an unfamiliar market. Before recruitment, obtain the institution’s required ethics review and informed consent, define eligibility and withdrawal, and preregister outcomes and analysis. Use simulated money and fictional companies; collecting personal balances or real trading activity is unnecessary.

| Outcome                     | Proposed evidence                                                                | Current app support and limitation                                                                                                                            |
| --------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Financial understanding     | Parallel pre/post questions with reviewed answer keys                            | Level checks record first-try accuracy; quizzes record first answers. Neither bank is a validated test, and neither has been independently reviewed           |
| Applied decisions           | Pre/post performance in comparable unfamiliar markets                            | Each chapter's Preview Battle and Chapter Boss play one scenario with two seeds. Same scenario, so not an unfamiliar transfer task; difficulty not calibrated |
| Retention                   | Delayed unseen checks at a prespecified follow-up                                | The daily review quiz repeats bank items weighted toward missed concepts; there is no scheduled delayed test                                                  |
| Risk behaviour              | Stop-loss use, position size and drawdown in unfamiliar markets                  | Results record stop-loss discipline, largest position, worst drawdown and fees per match; these are descriptive, not a validated risk measure                 |
| Plan adherence              | Compare a frozen prior plan with actual simulated decisions                      | Each match stores a plan (strategy, maximum loss) and compares the loss limit with the worst drawdown. Strategy adherence is not scored                       |
| Probability accuracy        | Optional confidence, first-attempt correctness and calibration analysis          | Quiz answers can carry `sure`/`think`/`guess`; only the Calibrated badge uses it. No calibration statistic is computed                                        |
| Reflection                  | Independent ratings of evidence, uncertainty and justified changes               | An optional post-match reflection is stored, not graded                                                                                                       |
| Usability                   | Task success, errors, time to first useful action and short interviews on mobile | No participant testing has been done                                                                                                                          |
| Engagement without pressure | Return rate and a survey of pressure or loss-chasing intent                      | Activity days and match counts are recorded; more play or more trades is not automatically beneficial                                                         |

The results screen's decision score (missions, plan kept, stop discipline, overtrading) is an unvalidated product heuristic. Do not use it as an outcome measure without validating it first.

Use alternate forms and counterbalanced presentation to reduce familiarity. If comparing with another experience, randomize assignment where practical, keep content/time exposure comparable and state unavoidable differences. Separate first attempts from retries (the game event log records attempt numbers and Gem-enabled daily retries), disclose attrition and missing confidence, and report uncertainty alongside descriptive change. Determine sample size from a prespecified primary outcome and a justified power or precision analysis; do not invent a convenient effect size.

Have independent reviewers check content accuracy and rubric agreement before the study. Establish a stopping and correction process for misleading content, unexpected distress or increased pressure to speculate. Do not infer real-market competence from a simulated gain.

Use voluntary participation, minimal event fields and a stated retention period. The owner-scoped [research exports](reference/research.md) and default-off consent records are implementation support; study exports, researcher access and participant data management require a separate approved protocol. Report what was actually collected and tested, including null or negative results.
